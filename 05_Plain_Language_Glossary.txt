## 0. 書き方の約束（4本共通）

1. 状態を表す語は、この表の「言葉」で書く。数字と記号は括弧で後ろに付ける。
   例：「大口が売った日が直近5週で7日（分配日 IX2＝7。6日以上は危険水準）」
   記号だけの行、英語だけの行を作らない。記号を消さない（過去のレポートや仕様との照合に使う）。
2. 冒頭ブロック（レポートの先頭。SendUserMessage の要約も同じ文で始める。行の名前はレポートごとに違う）：
   ## 今日のひとこと（3〜4行）
   米国株（日次・週次）：
   - 相場：〔言葉〕（記号）
   - 半導体・テクノロジー：〔言葉〕（記号）
   - やること：〔行動の目安を1行。5節の言い方。ヘッジは「置くかは判断」と添える〕
   - 長く持つ分の目安：〔○%（buy／sell、○月○日から）。短期の「やること」とは別の行〕
   半導体（日次・週次）：semis-data の docs/plain_language.md 0節（半導体／メモリー／行動の目安の3行）
   ## なぜその判断か（3〜5行）
   - 根拠を1行ずつ。「言葉 → 数字（記号）」の順。判定を押し上げた要因と抑えた要因を分けて書く
   - 最後の1行は「判断が変わる条件」：これが起きたら見方を変える、を数値で
3. 本文の各節は「言葉 → 数字（記号）」の順。表には「言葉」の列を置くか、数字の横に言葉を添える。
4. 巻末に「読み方」：そのレポートで使った記号だけを1行ずつ（この表から転記）。毎回同じでよい。
5. 禁止：記号だけで状態を言う（「Eのまま」「S1が0」）。閾値を記号だけで示す（「IX2>=5」→「大口が売った日が5日以上」）。
6. （2026-11-10）配信（通知で届く文）は1画面にする：冒頭ブロックと、前日・前回から変わった点が中心。変わっていない表や内訳は添付の本文だけに書く。本文も、変化を先に、変わっていない節は短く書く（分量の目安と短縮形は各手順書）。
7. （2026-11-10）数字の約束（4本共通）：
   ・騰落率・出来高・高値からの位置は、データ（market-data／semis-data の data ブランチ）の値だけを書く。記事の数字は取引時間中の値のことがあるので書かない（記事は理由の説明に使う）。
   ・倍率には基準を書く：「出来高が20日平均の○倍」「出来高が50日平均の○倍」「売買代金が50日平均の○倍」。「普段の○倍」とだけ書かない（基準が違う数字が同じ言葉で並ぶため）。
   ・同じものに2通りの数字を書かない。半導体の「上昇・下落」の割合は公式ステージ（market-data の stages。週足）の数字で書き、半導体側の簡易版（30週線の上下と線の向き）は「線の上で上向き／線の下で下向き」と別の言葉で書く。
   ・半導体の週次の見出しは、株価の状態と市況の見方を分けて書く（「やや強気」などのラベルだけで始めない。semis-data の judge.md）。

## 2. ステージ（個別株・ETFの局面。07追補 E6.2・E6.3）

書き方：「言葉（記号）」の順。例「下落入り（4A(-)、2週目、30週線の22%下）」「底固めの終盤・上抜け間近（1B(+)、上限まで6%）」。
「ステージ2のまま移行中」のような書き方はしない（v4.6bで廃止。上向きの線を大きく割った銘柄は3か4になる）。

| 記号 | 言葉 | 添える一言 |
|---|---|---|
| 1A | 底固めの始まり | 下げが止まったばかり。まだ買わない |
| 1 | 底固め | 横ばいで底を作っている |
| 1B | 底固めの終盤（上抜け間近） | 上限（resistance）まで○%。市場比の強さが改善。監視候補 |

| 2B | 上昇の終盤 | 上昇が長い・線の傾きが鈍った・市場比の強さが落ちた等（理由を書く）。新規は慎重に |

| 3B | 天井圏の終盤（崩れ間近） | 支え（support）の近く、または線が下を向いた。戻りで売る |

| 2→3 | 上昇が止まった | |

| 4→1 | 下げ止まって底固めに入った | |
| truncated | 局面の始まりがデータより前 | ベースの番号は未確認 |

業種の調子（stages.breadth のラベル。個別株のステージの割合から）：

| 記号 | 言葉 |

| spy_model_signal buy／sell | 長期の目安が「高い状態」に戻った／「20%以下が3日続く状態」になった（SPYの目安。3倍ETFにはそのまま当てはめない） |

「やること」の言い方（レジームから決める。ゲート該当が先）：
- A：通常どおり新規可。候補があれば発注計画へ
- B：強い銘柄に限って新規可
- E：小さく試す。候補があれば1〜2銘柄
- C：新規は原則見送り。持ち株は崩れの合図を確認
- D：新規なし。反発が本物になる合図（FTD）待ち
- F：新規なし。守り（ヘッジの条件を確認）
- Transition／仮の判定：様子見
- ゲート該当：「買ってはいけない条件に当たっている（〇〇）」を先に書く
- 候補0件：「候補なし」と明記。決算が近い銘柄：「決算前は見送り」
- FB1_stalling のとき：「抜けても伸びない地合い。抜けた後の続き（3〜5日）を見てから」
- ヘッジ（許可中は毎回）：「ヘッジ：条件成立（SPY、H1、損切り○○。置くかは判断）」または「ヘッジ：検討できる地合いだが今日は条件未成立」。許可外なら書かない
- 長期の目安（毎回1行）：「長く持つ分の目安 ○%（buy、○月○日から）」。短期の「やること」とは別の行に

## 7. 需給と不安の指数（08追補 B4.6a・B4.5a。観察専用）

| 記号 | 言葉 |
|---|---|
| 買い戻しの燃料（残り約○割） | 売りすぎた人が買い戻せる余地。プロの持ち高が軽いほど多い。棒（■＝残り、□＝使った分）と一緒に書く |
| 燃料：多い（約7割以上） | プロはすでに大きく売っていて、これ以上売る物が少ない。きっかけがあれば買い戻しだけで上がりやすい位置（上がる保証ではない） |
| 燃料：半分ほど（約4〜6割） | 買い戻しが進んでいる途中 |
| 燃料：少ない（約3割以下） | 買い戻しはほぼ終わった。ここから上がるには新しい買い材料が要る |
| hf_net（ネット・レバレッジの百分位） | プロ（ヘッジファンド）の買い持ちの量が、過去の範囲の下から何%の位置か |
| discretionary | 自分の判断で売買する投資家の持ち高 |
| systematic／CTA | 決まった規則で機械的に売買するファンドの持ち高（値動きに合わせて自動的に売り買いする） |
| 自社株買いの解禁（ブラックアウト明け） | 決算前の自粛期間が終わり、企業が自社株を買える状態 |
| VIX÷VIX3M（vix_over_vix3m） | 目先30日の不安 ÷ 3か月先の不安 |
| inverted（逆転、1以上） | 目先の不安のほうが大きい。あわてて保険（プット）を買う人が多く、荒れている最中 |
| tight（0.9〜1） | 差が小さい。警戒が残っている |
| normal（0.9未満） | 平常 |
| unwinding | 逆転が解けた。急いで買った保険を外す動き（ヘッジ外し）が進み、株の戻りを後押しした形 |
| VVIX／SKEW | VIXそのものの荒れ具合／大きな下落に備える保険の割高さ |
