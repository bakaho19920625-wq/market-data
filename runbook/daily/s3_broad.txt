# 3. Broad（短く）

- 見出し：`## 3. Broad`
- 日々動く項目だけ：S&P500・NASDAQ（signals.market）、SOX（signals.market に無いので SOXX＝signals.tech_etf で代用）、VIX、2年・10年金利、HY OAS、ドル円、原油、当日〜翌営業日のイベント。
  数字は機械取得を先に読む（記事の数字より先。毎朝 Web検索に頼っていたため、出典が弱く、2年金利と HY OAS は「未取得」が続いていた）：
  ・当日の動き（基準日と同じ日）：signals.market の ^GSPC・^IXIC・^VIX と、ETF の前日比で向きを書く。
   長期金利＝TLT（上がれば金利は低下）、信用＝HYG、ドル＝UUP、原油＝USO、金＝GLD。
   「原油（USO）−4.0%」のように ETF 名を添え、先物や指数そのものの値と混ぜない。
  ・水準（1〜2営業日遅れでよい。必ず日付を添える）：semis-data の data ブランチ macro_daily.csv（FRED。`git clone -q --depth 1 --branch data https://github.com/bakaho19920625-wq/semis-data.git /home/claude/sd-data`）から、
    2年金利（DGS2）、10年金利（DGS10）、10年実質金利（DFII10）、HY OAS（BAMLH0A0HYM2）、ドル指数（DTWEXBGS）の最新の行。
    状態は verified（出典 FRED）。
    DGS2 と BAMLH0A0HYM2 は 2026-11-10 以降のデータにある（無い日は「未取得」）。
    ドル円（USDJPY=X）と10年金利の当日値（^TNX）は同じクローンの daily_signals.json の table にある。
    semis_manifest.json の us_as_of が今日の基準日と同じときだけ使う（7:07 の時点では前の取引日のままのことがあり、その場合は書かないか、日付を添える）。
  ・Web検索は、当日〜翌営業日のイベント（経済指標・決算・FOMC）と、指数が大きく動いた日の理由の確認だけに使う（合計2回まで。WebFetch は検索結果に出たURLしか取れない）。
   指数・金利・為替・原油の数字を記事から取らない。
   原油の水準（WTI の価格）が要る日だけ、理由の記事にある値を reported_unverified と明記して1つ書いてよい。
  ・どれも取れない項目は、直近の週次の値を「転記（週次○/○）」と明記して使うか「未取得」と書く。
   推測で埋めない。
   日次ではマクロ値は補助情報で、Tapeの判定には使わない。
- Broad点は週次で確定。
  日次は「据置（前回週次：○点・○○）」を基本とし、判定帯をまたぐ明確な変化がある場合だけ暫定値と理由を書く。
- マクロ値は state に保存しない（表示のみ。保存は週次）。
- VIX の後に期間構造を1句：signals.vol_term の vix_over_vix3m と state_ja、unwinding が真なら「逆転が解けてヘッジ外しが進んだ形」
  （例「VIX 19.9。目先と3か月先の差は小さい（VIX÷VIX3M 0.97、11/6 まで逆転）」）。
  vol_term が無い・vix3m が null の日は書かない。
