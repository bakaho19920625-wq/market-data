## 0. この追補の位置づけ

きっかけ（2026-11-14）：
・QLD・TQQQ（ナスダック100の2倍・3倍ETF）を買う時期の判断材料がほしい、という依頼。
・半導体レポートの「底の3条件」は、半導体の中身と半導体指数で見た売られ尽くしで、QQQ の底は測っていない。
  2026-11-05 は半導体で3条件がそろったが、ナスダック100で50日線の上にいた銘柄は約5割だった。
・半導体の3条件で QQQ 系を買うと、下げ相場の入り口（2000年10月、2001年4月、2008年1月）でも点き、QQQ はその後 −19〜−62% 下げた。
  ナスダック100の構成銘柄で同じ形の物差しを作ると、この3回は点かず、失敗が減った（下の「検証」）。

**観察専用**。Tapeレジーム（C15.1）、Broad の点数（B部の算式）、L/H、買い判定、長期SPY配分モデル（F10）は変えない。
版：specification_version は 4.6 のまま（観察項目の追加。Full の理由にしない）。signals.json の definition_version も変えない。
部分の版：QW-1.0（signals.json の qqq_washout）。
記号：P＝本プロジェクトの独自定義。閾値はすべてPで、外部の公式な読み方ではない。

## F11 QQQの売られ尽くし（P、QW-1.0）

### 定義
| 項目 | 定義 |
|---|---|
| 対象 | ナスダック100のいまの構成銘柄（main の ndx100_constituents.csv） |
| pct50 | 終値が50日単純移動平均より上の銘柄の割合（%）。線は50日分の足がそろった銘柄だけで計算する（S&P500 の BR1 と同じ形） |
| pct150 | 同じく150日 |
| 点灯（lit） | pct50 < 5.0 かつ pct150 < 15.0。データのある銘柄が一覧の8割未満の日は判定しない（coverage_low） |
| 局面の起点 | 点灯した日のうち、直前の点灯日から40営業日以上あいた最初の日 |
| 損切りの線 | 起点の日の QQQ 終値 × 0.93。終値で判定する |
| 状態 | none＝起点が無い／active＝起点のあと、線の上／broken＝QQQ の終値が線以下になった／handed_over＝QQQ が200日線の上で、線が21営業日前より上 |
| 状態の確定 | broken と handed_over は、なった日で確定し、次の起点まで変えない。起点の翌日から判定する |

閾値（5%・15%・40営業日・−7%・8割）は検証済みの値なので変えない。「基準に近い」などの段階も足さない（検証していない線を作らないため）。

### 入力と計算
- 一覧：main の ndx100_constituents.csv。3・6・9月の定期見直し、12月の年次入れ替え、臨時の入れ替えの発表のあとに手で更新し、`# list_as_of:` の日付を書き換える（2026-05 からのナスダックの新ルールで、入れ替えは年4回ある）。
- 日足：S&P500 の日足（prices_sp500.csv.gz）に、S&P500 に無い銘柄の日足（prices_ndx100_extra.csv.gz、約2年）を足す。終値は分割調整済み・配当非調整。
- fetch_data.py が毎朝、breadth.csv に3系列（ndx100_pct_above_50sma、ndx100_pct_above_150sma、ndx100_members_with_data）を出し、manifest.json の breadth.ndx100 に状態を書く。
  一覧が無い、または追加の取得に失敗しても、S&P500 の市場内部とほかの取得は止めない（breadth.ndx100.status が skipped／failed になる）。
- analyze.py が signals.json の qqq_washout を出す。QQQ の200日線は tape.checklist と同じ足（P.C・P.s200）で見る。
- proxy：いまの構成銘柄で過去を計算するので、生存者バイアスがある（S&P500 の市場内部と同じ扱い）。

### 損切りの線を −7% にした理由
- うまくいった7回は、半年以内の下げが最大 −5.5%（2022-09）。失敗した3回（2001年、2002年、2008年）は −7.6% 以上下げた。間に線を引ける。
- 200日線のルール（QQQ が200日線の上で線が上向きなら持ち、線を割ったら売る）を土台に、点灯の翌日に買って線で売った場合（2000-08〜2026-11、年率／最大の下げ）：
  | 損切り | QLD（2倍の計算） | TQQQ（3倍の計算） |
  |---|---|---|
  | −5% | 16.9%／−55% | 20.4%／−74% |
  | −7% | 18.3%／−55% | 22.4%／−74% |
  | −10% | 15.6%／−76% | 17.2%／−92% |
  参考：200日線だけは QLD 13.2%／−47%、TQQQ 15.6%／−67%。
- 2倍・3倍は QQQ の日々の騰落率を2倍・3倍にしてコストを引いた計算で、実物の年間成績との差は最大2ポイント。

### 限界
- 下げ相場の途中でも点く（2001年、2002年、2008年）。3回とも損切りの線を割った。
- 基準ぎりぎりで点かなかった回がある：2022-06（pct50 が 5.6%）、2024-08（pct150 が 16.2%）。
- 2000〜2010年は、200日線だけより少し悪い（TQQQ の年率 2.5% → −0.6%）。上乗せは2011年以降の結果。
- 線の位置を少し変えると、TQQQ の年率は 15〜22% の間で動く。確かなのは「半導体の3条件より失敗が少ない」まで。
- 古い時期は上場廃止の銘柄が抜けている（2003年は102銘柄中68銘柄）。
