・ブレイクアウトの本命とダマシは、抜けた瞬間ではなく、抜けた後に続いたか（フォロースルー）で見分ける。
・ステルス・ベアマーケット（隠れ弱気相場）：指数は高値圏なのに、水面下では大多数の個別株が20%以上下げている状態。
・2026年10月末は逆の形：AI・大型テックが崩れ（ナスダック100が1か月で約−9%）、それ以外のS&P500は高値圏。

## C15.1a FB1の伸び（FB1x）P

FB1 の各事象について、ブレイク当日の終値からの平均リターンを D+3／D+5／D+10 で出す（v4.2から出力済み：d5_avg_ret_pct 等）。

  FB1_stalling（伸びない）＝ D+5成熟件数が20件以上 かつ D+5平均リターン < 0 かつ D+10平均リターン < 0
  FB1_extends（伸びている）＝ D+5成熟件数が20件以上 かつ D+5平均リターン >= 0 かつ（D+10が未計算 または D+10 >= 0）

意味：維持率が高くても平均リターンがマイナスなら、「抜けた水準は割らないが、抜けた日より下で推移している」＝フォロースルーがない。
どちらでもない場合（標本不足、D+5とD+10の符号が分かれる）は中立。

## C15.1b 市場内部の拡張（BR4・BR5）P

母集団：S&P500の現在の構成銘柄（sp500_constituents.csv、GICSセクター）。生存者バイアスがあるためproxy。
グループ：
・sp500＝全体（基準：SPY）
・tech＝Information Technology＋Communication Services（基準：XLK）
・ex_tech＝それ以外（基準なし。techとの比較用）

指標（各グループ、当日と4週前＝20営業日前）：
・pct_down20：終値 <= 52週高値（日中高値、252本）×0.80 の銘柄の比率（%）。
・pct_above_50sma：終値 > 50SMA の銘柄の比率（%）。
・グループの8割以上に値がそろわない日は null（欠損を0で埋めない）。

ラベル（基準ETFがあるグループだけ）：
・stealth（隠れ弱気）：pct_down20 >= 50% かつ 基準ETFの dd >= −10%（高値圏。C15.1のCの必須と同じ水準）
・broad_decline（全面的な下落）：pct_down20 >= 50% かつ 基準ETFの dd < −10%
・watch（隠れ弱気の警戒）：40% <= pct_down20 < 50% かつ 基準ETFの dd >= −10%
・それ以外：null

BR4＝sp500 の pct_down20・ラベル。BR5＝tech の pct_down20・50日線上比率・ラベル。
tech_minus_ex_tech_down20_pt＝tech と ex_tech の pct_down20 の差（ポイント）。

大型株主導の下落（megacap_led）：QQQのSPY比1か月（21営業日） <= −3% かつ RSP/SPYの4週変化 >= +2%。
（ステルス・ベアの逆の形。指数を大型株が押し下げ、均等加重はむしろ強い）

使い方：
・Tapeレジームに使うのは BR4 の stealth だけ（Cの支持項目）。
・BR5（tech）は市場全体のレジームに使わない。半導体・テクノロジー節の環境認識として必ず表示する
  （ユーザーの投資対象は半導体とテクノロジーの2セクター）。
・megacap_led はIX3の理由の書き分けと、レポートの説明に使う。

## C15.1c 指数の崩れガード（IX3）P

  IX3 ＝（SPYが終値で50SMAの下 または QQQが終値で50SMAの下）かつ IX2（有効分配日数） >= 5

IX3が成立している間は、Eの内部回復入口（b）を使わない。
理由の表記：megacap_led が真なら「大型株主導の崩れ」、偽なら「指数の崩れ」。

## C15.1d 判定条件（v4.4の差分を反映した全文。判定順 F → C → D → E → A → B は不変）
判定順の補足：Eの入口が成立していても、SPY・QQQがともにIX1（終値 > 50SMA > 200SMA、200SMAが上向き）なら E を飛ばして A／B を先に判定する（00 C15.1「AまたはBを優先」と同じ。エンジンの実装も同じ）。
補助出力：tape.checklist.E_recovery_items_met＝Eの回復項目4つの充足数、C_support_met＝Cの支持項目の充足数（Fの日も出す）。

F 弱気・高リスク：変更なし。

C 成熟・分配
必須：SPYまたはQQQが52週高値から−10%以内。
かつ、次のどちらか：
 (i) IX3が成立（理由：高値圏／大型株主導の崩れ または 指数の崩れ）
 (ii) 支持2つ以上：IX2 >= 5／BR1が4週で10pt以上低下／BR2が0未満かつ4週前より悪化／
      ［v4.4］FB1 < 40% または FB1_stalling／BR3 <= −2%／［v4.4］BR4が stealth
支持の件数は C_support_met として出力する。

D 底打ち試行：変更なし（IX3でEの(b)が使えない場合、高値圏でなければDになる）。

E 確認された回復
 (a) FTD入口：変更なし。ただし支持の「FB1 >= 50%」は［v4.4］FB1_stalling のときは数えない。
 (b) 内部回復入口：SPYとQQQがともに上向き200SMAの上、かつ回復項目2つ以上、［v4.4］かつIX3が不成立。

A 攻勢：必須の「FB1 >= 50%（標本20件以上）」に［v4.4］「かつ FB1_stalling でない」を加える。

B 選別的強気・Transition：変更なし。

## レポートでの書き方（正本は daily_runbook／weekly_runbook。ここは要点だけ）

日次（daily_runbook 第2・3・5節）・週次（weekly_runbook 第5節）とも：
1. Tape のチェックリスト表に、FB1 の行を「維持率／平均リターン（D+5・D+10）／伸び判定」の3つで書く。
   stalling なら「抜けた水準は守るが伸びていない（ダマシが多い地合い）」と一言添える。
2. Tape の表に IX3 と BR4 を加える。IX3 が成立していれば理由（大型株主導の崩れ／指数の崩れ）を書く。
3. 半導体・テクノロジー節の冒頭に「テック内部」1行：BR5（tech の pct_down20 と4週前、50日線上比率、ラベル、XLKの位置）と
   ex_tech との差。stealth なら「XLKは高値圏だが、構成銘柄の過半が高値から20%以上下げている（隠れ弱気）」、
   broad_decline なら「XLKも−10%超で、下げが表面化」と書く。
4. megacap_led が真なら、「市場全体の中身は改善しているが、大型・AI株主導で指数が崩れている。半導体・テクノロジーだけに
   投資する立場では、市場全体の改善を自分の領域の追い風と読まない」と書く。
5. いずれもproxy（現在の構成銘柄、生存者バイアス）と注記する。

## 既知の限界

・現在のS&P500構成銘柄で過去を計算するため、生存者バイアスがある（脱落した弱い銘柄が入っていない）。
・prices_sp500 は約2年分のため、52週高値がそろうのは直近約1年。それより前は null。
・ナスダック100の構成銘柄は取得していない。tech（IT＋通信）で代用している。
・ブレイク後の出来高（フォロースルーの出来高）は判定に使っていない（今後の候補）。
・閾値（40%・50%・−10%・分配日5・−3%・+2%）はP。成績による校正はしていない。
