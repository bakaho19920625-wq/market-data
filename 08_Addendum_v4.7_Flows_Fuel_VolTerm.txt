## B4.6a 買い戻しの燃料計（P、FG-1.0）

### 考え方（レポートでもこの順で説明する）
1. 大きく下げた直後の上げは、まず「売りすぎた人の買い戻し」で起きる。新しく買いたい人が増えたわけではない。
2. プロ（ヘッジファンド等）がすでに持ち高を大きく減らしていれば、これ以上売る物が少なく、買い戻す余地が大きい。これを「燃料が多い」と呼ぶ。
3. 持ち高がふだんの水準まで戻ると、買い戻しは一巡する（燃料切れ）。そこから先も上がるには、業績や政策の改善という新しい買い材料が要る。
   問題が残ったままなら、戻ったところは売られやすい。
4. 燃料が多い＝上がる、ではない。悪材料が続けば、持ち高が軽いまま下がる（2022年がその例）。分かるのは「上げ始めたら速く、売りは出にくい位置か」まで。

### 入力（公表・報道された数字だけ。推測しない。本文 B2「有料・非公開のHF、CTA、ガンマ、0DTE内部データを推測しない」のとおり）
「位置」＝過去の範囲の中で、いまの持ち高が下から何%のところにあるか（発表元が出す百分位をそのまま使う。0%＝過去いちばん軽い、100%＝いちばん重い）。

| 記号 | 誰の持ち高か | 使う数字 | 主な発表元 |
|---|---|---|---|
| ① hf_net | プロ（ヘッジファンド）の買い持ち | 米国株ロング・ショート戦略のネット・レバレッジの百分位（5年を優先、無ければ1年。どちらかを書く） | Goldman Sachs プライムブック。無ければ Morgan Stanley・JPMorgan のプライムブローカー部門の同じ種類の数字 |
| ② discretionary | 自分の判断で売買する投資家 | discretionary investor positioning の百分位 | Deutsche Bank（週次の Investor Positioning and Flows） |
| ③ systematic | 決まった規則で機械的に売買するファンド | systematic strategies positioning の百分位。無ければ CTA の S&P500 の百分位 | Deutsche Bank。無ければ Goldman Sachs の CTA 推計 |

・百分位が公表されていない入力（「大幅に低下」などの言葉だけ、z値だけ）は使わない（言葉は sector_note に書く）。自分で百分位に直さない。
・基準日が14日より古い入力は計算から外し、「古い」と書く。

### 計算
・位置の平均＝使えた入力の位置（%）の単純平均。
・**残りの燃料（%）＝100 − 位置の平均**。10%刻みに四捨五入して「残り約○割」と書く（細かい数字に意味はない）。
・使えた入力が2つ未満なら「判定できず」。
・水準（P）：残り約7割以上＝**多い**／約4〜6割＝**半分ほど**／約3割以下＝**少ない（買い戻しはほぼ一巡）**。
・棒：マス10個のうち、残りの割数だけ「■」、残りは「□」。例：■■■■■■■■□□ 残り約8割。
・前回比：前回の残り（prev.remaining_pct）と並べる。減り方が速いほど、買い戻しが速く進んでいる。

試算（11/6 週）：① 0%（5年。GS）、② 3%（DB）、③ 44%（DB）→ 位置の平均 15.7% → 残り 84.3% → **残り約8割（多い）**。

### 言葉（05 の7節にも同じものを置く）
| 水準 | レポートに書く言葉 |
|---|---|
| 多い（約7割以上） | プロはすでに大きく売っていて、これ以上売る物が少ない。きっかけがあれば買い戻しだけで上がりやすい位置。ただし悪材料が続けば、軽いまま下がることもある |
| 半分ほど（約4〜6割） | 買い戻しが進んでいる途中。まだ余地はあるが、最初ほどの勢いは出にくい |
| 少ない（約3割以下） | 買い戻しはほぼ終わった。ここから上がるには新しい買い材料が要る。問題が残っていれば、戻りは売られやすい位置 |

### 燃料とは別に書く「これから出る売り・買い」（flows。燃料計の計算には入れない）
| 項目 | 中身 | 読み方 |
|---|---|---|
| 機械的な売り・買いの見込み | CTA の今後1週間・1か月の売買見込み（相場が横ばいの場合。上昇・下落の場合があれば併記）。発表元を書く | 売りの見込みが残っている間は「買い戻しの前に、まだ出てくる売りがある」 |
| 機械的に売買するファンドの位置 | CTA の百分位（S&P500・ナスダック100）。③と同じ数字なら重ねて書かない | |

| 個人投資家 | 買い越し・売り越しの連続日数や金額（報道があれば） | |
| レバレッジETF | 残高の増減、引け前の機械的な売買額（報道があれば） | 大きいほど引けにかけて値動きが増幅されやすい |

### やってはいけないこと
・燃料計を買い・売りの合図として書かない。「多い」を「底」「上がる」、「少ない」を「天井」「下がる」と書かない。
・百分位が公表されていない入力を、自分で推計して埋めない。違う週の数字を同じ週のものとして並べない（as_of を必ず見る）。
・X（旧Twitter）の投稿や画像だけを出典にしない（発表元と掲載媒体が分かる記事で確認できた数字だけ）。
・Tape・Broad の点数・L/H・ゲートの判定に使わない。

## B4.5a 不安の指数（VIX）の期間構造（P、VT-1.0）

本文 B4.5 の「VIX、VVIX、SKEW」「先物期間構造、VIX9D／3M」を、毎日機械的に出す。
tickers.txt に ^VIX9D・^VIX3M・^VVIX・^SKEW を足し、解析エンジンが signals.json の vol_term に出す（Yahoo Finance 非公式。取れない日は null）。

| 項目 | 中身 |
|---|---|
| vix／vix9d／vix3m | 今後30日／9日／3か月の値動きの見込み（不安の大きさ） |
| vix_over_vix3m | VIX ÷ VIX3M。**1以上＝逆転**、0.9未満＝平常、その間＝差が小さい |
| state／state_ja／days_in_state | いまの状態（inverted／tight／normal）と、その状態が続いている営業日数 |
| inverted_days_in_window／last_inverted_date／bars_since_inverted | 直近20営業日の逆転の日数、最後に逆転した日、そこからの営業日数 |
| peak_ratio_in_window／peak_ratio_date | 直近20営業日の比率の最大と、その日 |
| unwinding | 直近10営業日に逆転があり、いまは逆転が解けて、比率が5営業日前より低い |
| vvix／skew | VIXそのものの荒れ具合／大きな下落に備える保険の割高さ（水準の転記だけ。閾値は置かない） |
| missing | 取れなかった指数 |

読み方（言葉は 05 の7節）：
・逆転（inverted）：目先の不安が3か月先より大きい。あわてて保険（プット）を買う人が多く、株は荒れている最中。
・逆転が解けた（unwinding＝真）：急いで買った保険を外す動き（ヘッジ外し）が進んだ形。保険の売り手が株を買い戻すので、株価の戻りを後押しすることが多い。
  ただし外し終われば後押しも終わる。燃料計と同じで、上がる保証ではない。
・平常（normal）：保険の需要は落ち着いている。

本文との関係：
・本文 B5・B8・D4（信用・流動性ゲート）にある「VIXバックワーデーション」は、vol_term.state＝inverted で確認する。
  これまで VIX3M が取れず未確認（null）だった条件が、確認できるようになる。ゲートの定義（HY／IG急拡大、VIXバックワーデーション、銀行ストレス等が
  Tape悪化と同時進行）は本文のまま。逆転だけでゲートを立てない。
・Tapeチェックリストの (5)「VIX<25 かつ HYG>50SMA」は変えない。

レポートでの書き方：
・週次 13節の表：VIX3M、VIX÷VIX3M（状態と日数）、VIX9D、VVIX、SKEW を signals.vol_term から転記する（missing と書くのは vol_term.missing にある指数だけ）。
  解釈に1行：「逆転は○/○に最大（比率○）、いまは○○」。
・日次 第4節 Broad の VIX に続けて1句：「VIX 19.9。目先と3か月先の差は小さい（VIX÷VIX3M 0.97、11/6 まで逆転。逆転が解けてヘッジ外しが進んだ形）」。
・signals.json に vol_term が無い（古いデータ）か、vix3m が null の日は、従来どおり missing と書く。

## 試算と検証（2026-11-10）
・解析エンジン：変更前後で signals.json（vol_term を除く全項目）・screen.csv・setups.csv・ledger.json が完全に一致することを、
  data ブランチ（基準日 2026-11-09）のコピーで確認した。4指数を足しても、個別株の母集団・RS百分位・市場内部は変わらない
  （tickers.txt の「指数・市場全体」の区分に置くため、is_stock_group が偽）。指数が取れない日・一部欠ける日も vol_term が null になるだけ。
